    Class TpCopyCode

    Bouton de copie de code basé sur <tp-icon>, avec feedback visuel, changement temporaire d’icône et animation.

    The target can be defined as:

    • via l’attribut for, qui référence l’id d’un élément cible
    • via la propriété forElement, qui reçoit directement un HTMLElement

    Target resolution:

    1. forElement
    2. attribut for

    Content extraction:

    1. getValue() si disponible
    2. getCode() si disponible
    3. textContent

    Example

    <tp-box>
    <tp-box id="intro-copy-code" style="width:300px">
    <pre><code>const answer = 6 * 7;</code></pre>
    </tp-box>
    <tp-copy-code for="intro-copy-code"></tp-copy-code>
    </tp-box>

    Tagname

    tp-copy-code

    Attr

    for = "" - Identifiant de l’élément cible.

    Attr

    icon = "copy" - Nom de l’icône affichée à l’état normal. Valeur par défaut : copy.

    Attr

    success-icon = "check" - Nom de l’icône affichée après une copie réussie. Valeur par défaut : check.

    Attr

    error-icon = "warning" - Nom de l’icône affichée après une erreur. Valeur par défaut : warning.

    Attr

    copied-text = "Copied!" - Libellé accessible après une copie réussie. Valeur par défaut : Copied!.

    tp-copy-code-success Émis quand la copie a réussi. tp-copy-code-error Émis quand la copie a échoué.
