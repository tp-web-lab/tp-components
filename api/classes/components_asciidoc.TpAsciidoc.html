    Class TpAsciidoc

    Renders inline or external AsciiDoc as semantic HTML.

    Example

    <tp-box><tp-asciidoc><script type="tp/asciidoc">This paragraph uses *AsciiDoc*.</script></tp-asciidoc></tp-box>

    Tagname

    tp-asciidoc

    Attr

    src = "" - URL of an external AsciiDoc source file. tp-asciidoc-rendered Emitted after conversion and runtime initialization complete.
