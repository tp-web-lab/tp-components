    Class TpBase

    Base class for tp-* components.

    This class factors out a few recurring behaviors:

    • injecting a global stylesheet once
    • automatic marking of the host with data-tp-base-host
    • simplified read/write handling for boolean attributes
    • batch attribute removal
    • typed element lookup in the DOM subtree

    The <tp-base> component can also be used directly as a neutral demo or test element.

    Example

    <tp-base>This element provides the common tp-components foundation.</tp-base>

    Tagname

    tp-base

    Attr

    dir = "" - Text direction (ltr, rtl, or auto).

    Attr

    lang = "" - Language tag used by the component content.

    Attr

    data-tp-help-src = "" - URL of the component API manifest used by the help system.

    Attr

    data-tp-markdown-source = "" - Source document URL used to resolve relative resources in generated help.
