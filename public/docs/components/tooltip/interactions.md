### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Hover over the associated control | Open the tooltip. |
| Move the pointer into the tooltip | Keep it open to read, select text or follow links. |
| Scroll inside scrollable content | Scroll the content without closing the tooltip. |
| Leave both the associated control and the tooltip | Close after a short delay, unless keyboard focus remains inside. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Focus the associated control to open the tooltip, then move through any links or controls inside it. |
| <kbd>Escape</kbd> | Closes the tooltip. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User Help for the component under the pointer, or the focused component if none is hovered. Include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component from the hierarchy under the pointer, or around the focused component, then open its help. <kbd>Alt</kbd> is <kbd>Option</kbd> on macOS; include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
