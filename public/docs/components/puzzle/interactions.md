### User interactions

#### Mouse interactions

| Action | Result |
| --- | --- |
| Drag a piece | Moves it with a mouse, pen or touch. An upright piece snaps near its correct target. |
| Right-click a piece | Opens its rotation menu at the pointer. |
| Rotate +90° / Rotate −90° or Rotate +60° / Rotate −60° | Rotates the selected piece clockwise or counterclockwise by 90° (square/interlocking) or 60° (triangle/hexagon), from the menu or toolbar. |
| Show image | Toggles the reference image in the target frame without changing placements. |
| Undo / Redo | Reverses or reapplies an accepted move or rotation. |
| Shuffle | Rearranges every piece in the tray and clears move history. |
| Click outside the rotation menu | Closes the menu. |

#### Keyboard interactions

| Key | Result |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Moves focus through controls and pieces. |
| Arrow keys | Moves the focused piece by 0.05 cell units; hold <kbd>Shift</kbd> for 0.25 units. |
| <kbd>R</kbd> / <kbd>Shift</kbd>+<kbd>R</kbd> | Rotates the focused piece by ±90° (square/interlocking) or ±60° (triangle/hexagon). |
| <kbd>ContextMenu</kbd> / <kbd>Shift</kbd>+<kbd>F10</kbd> | Opens the focused piece's rotation menu. |
| <kbd>Escape</kbd> | Cancels a drag or closes the rotation menu and returns focus to the selected piece. |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undoes or redoes a move while a piece is focused. <kbd>Command</kbd> is also accepted. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates a focused toolbar button or menu action. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Opens User help for the component under the pointer, falling back to focus. <kbd>Shift</kbd> may be needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Opens contextual component documentation. |
