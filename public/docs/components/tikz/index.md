The custom `<tp-tikz>` element renders TikZ drawings.

<div class="tp-component-doc-example">

<!-- tp-docgen:introduction:start -->
``` raw html
<tp-tikz scale="1.8" label="Linear, sine and exponential functions"><script type="tp/tikz">\begin{tikzpicture}[domain=0:4]
  \draw[very thin,color=gray] (-0.1,-1.1) grid (3.9,3.9);

  \draw[->] (-0.2,0) -- (4.2,0) node[right] {$x$};
  \draw[->] (0,-1.2) -- (0,4.2) node[above] {$f(x)$};

  \draw[color=red]    plot (\x,\x)             node[right] {$f(x) =x$};
  % \x r means to convert '\x' from degrees to _r_adians:
  \draw[color=blue]   plot (\x,{sin(\x r)})    node[right] {$f(x) = \sin x$};
  \draw[color=orange] plot (\x,{0.05*exp(\x)}) node[right] {$f(x) = \frac{1}{20} \mathrm e^x$};
\end{tikzpicture}</script></tp-tikz>
```

## Usage

### Initial content

::: tp-tabs
Inline source
: Use a `script` with `type="tp/tikz"` to preserve backslashes and literal source.

Attribute
: Set `value` with a source string. An empty value clears the output.

External file
: Set `src` to a `.tex` file. A nonempty `src` takes precedence over the other inputs.
:::

### Configuration

Set `scale="1.8"` to enlarge the complete SVG, including labels, strokes and animations. The default is `1`; positive values below `1` reduce the drawing. Invalid or nonpositive values use `1`. The drawing fits within the available width. Changing `scale` resizes the existing SVG without recompiling or restarting its animation.

Provide a literal source in a `script[type="tp/tikz"]`, set `value`, or load a file with `src`. Source precedence is `src`, then `value`, then inline content. An empty `value` clears the output. Relative file URLs resolve against the containing document. Source changes replace the previous result; stale requests are discarded.

Use a tikzpicture environment, with definitions inside the source. The libraries attribute loads comma-separated TikZ libraries. Compilation takes place in an isolated frame. Initial compilation requires the remote TikZJax WebAssembly engine and TeX core; later updates compile again. Only south, north, east and west fading presets are supported by the patched renderer.

### Importing

::: tp-tabs
script
: Autoloading:

  ```html
  <script type="module" src="tp-loader.js"></script>
  ```

  Cherry picking:

  ```html
  <script type="module" src="/path/to/components/tikz/tikz.js"></script>
  ```

import
: ```js
  import "/path/to/components/tikz/tikz.js";
  ```

bundler
: ```js
  import "@tp/tp-components/components/tikz/tikz.js";
  ```
:::

## Examples

The examples below include illustrations from the official documentation for [tikz](https://tikz.dev/tikz) and a metallic discs drawing.

<!-- tp-docgen:example-descriptions:start -->
Basic usage
: Compare the red linear function, blue sine function and orange exponential function on a shared grid with labeled axes.

Javascript API
: Create the Basic usage example entirely with JavaScript and explicit component imports. Run the example to obtain the same content and interactions without the autoloader.

Trie graph
: Follow the red path through the trie and inspect the shared prefixes. This example loads graphs and arrows.meta and defines the pale yellow background used by edge labels.

Text decoration
: Read the text following the ellipse outline. The text decoration is drawn after the filled shape.

Path intersections
: Locate the two red intersection markers between the ellipse and the rotated rectangle. Named paths let TikZ calculate their positions.

Orbital animation
: Watch Earth orbit the Sun and the Moon orbit Earth while the Sun changes color. The orbital periods are 36.5 seconds and 2.8 seconds.

Turtle star
: Follow five turtle steps and 144-degree turns to draw a blue filled star.

Spy magnification
: Compare the two magnified circular views of the Koch curve. The green segment connects the named spy nodes.

Lindenmayer tree
: Inspect the branching pattern generated by four iterations of a Lindenmayer rule. Step lengths and angles include randomized variations.

Metallic discs
: Inspect three stacked metallic discs built from reusable TikZ pics. Gradients and layered translucent shapes create the reflections and soft ground shadow.
