### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| :tp-icon:{name="arrow-expand-horizontal" size="2em"} :tp-icon:{name="arrow-expand-vertical" size="2em"} Orientation icon, top right | Switch between horizontal and vertical layouts. |
| Expression field | Edit the expression or select a part to transform. |
| <!-- button --> Digits, dot, comma, parentheses and operators | Insert at the caret or replace the selection. |
| <!-- button --> Scientific function | Wrap the selection or expression in the chosen function. |
| <!-- button --> e / π / Rand | Insert a constant or a random number. |
| <!-- button --> Deg / Rad | Toggle the trigonometric angle unit. |
| <!-- button --> = | Evaluate and display the result, or explain an error. |
| <!-- button --> AC | Clear the expression and result message. |
| <!-- button --> ⌫ | Delete the selection or character before the caret. |
| <!-- button --> ± | Negate the selection or expression. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between the expression and keypad buttons. |
| <kbd>Enter</kbd> / <kbd>=</kbd> in the expression | Evaluate the expression. |
| <kbd>Escape</kbd> in the expression | Clear the expression and message. |
| <kbd>←</kbd>/<kbd>↑</kbd>/<kbd>→</kbd>/<kbd>↓</kbd>, <kbd>Backspace</kbd>, <kbd>Delete</kbd> in the expression | Move the caret or edit text normally. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> on a button | Activate that key. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User help for the component under the pointer, falling back to the focused component. <kbd>Shift</kbd> may be needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component from the hierarchy under the pointer, or around the focused component, then open its help. <kbd>Alt</kbd> is <kbd>Option</kbd> on macOS; include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
