### User interactions

#### Mouse interactions

| Action | Result |
| --- | --- |
| Select generated text | Select code in the embedded readonly editor. Its copy and save commands belong to tp-code-editor. |

#### Keyboard interactions

| Key | Result |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open contextual help for the component under the pointer or with focus; Shift may be needed for ?. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Open the component viewer. |

There are no component-specific buttons or editing shortcuts. The embedded editor provides its own controls and help.
