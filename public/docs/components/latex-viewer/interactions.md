### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| :tp-icon:{name="code" size="2em"} Show code | Show or hide the editable LaTeX source. |
| :tp-icon:{name="eye-outline" size="2em"} Show output | Show or hide the output. |
| Example | Select a document from the loaded examples. |
| :tp-icon:{name="language-html" library="tp" size="2em"} Rendered HTML | Display the rendered document. |
| :tp-icon:{name="code" library="tp" size="2em"} Generated HTML | Display the generated HTML as read-only code. |
| :tp-icon:{name="keyboard-f1" size="2em"} Toggle editor toolbar | Show or hide the editor toolbar. |
| :tp-icon:{name="refresh" size="2em"} Reset | Restore the selected example's initial source. |
| :tp-icon:{name="play" size="2em"} Run | Render the current source. |
| Fullscreen / Exit fullscreen | Expand the entire component to fullscreen or return to its normal size. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Run the current source from the viewer, including while editing code. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between controls. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activate a focused button. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open help for the component under the pointer, falling back to the focused component. Include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component from the hierarchy and open its help. Include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
| <kbd>Esc</kbd> | Exit fullscreen. |
