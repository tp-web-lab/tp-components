## Usage


See [Reference scope](#/components/references.md) for `data-tp-reference-scope`, nested boundaries and an editable example with repeated identifiers.

### Authoring

The `href` begins with `^` for a note, `@` for a bibliography entry, `%` for a glossary entry, `!` for an index entry, or `=` for an equation, followed by the exact `ref` identifier. Identifiers may contain punctuation and are not interpreted as CSS selectors. Ordinary URLs are not supported.

Reference labels are generated from their kind: `^identifier` displays a superscript `[n]`, `@bib` displays `[bib]`, and `%entry` displays `entry` with a dotted underline. Authored child text does not override this format. Each distinct note receives a number at its first citation in the current document scope; later citations of the same note reuse it. Adding, moving, changing or removing citations updates both the numbers and the note lists. Missing entries display a disabled reference until a matching definition becomes available. Definitions can be placed before or after references. Their content is shown on hover, focus or activation, and Escape dismisses the tooltip. Keep interactive controls in a generated list rather than in a tooltip.

References and lists use the nearest `data-tp-reference-scope`, rendered markup document, `article` or `main`, falling back to the page body. Nested document scopes are independent. Identifiers should be unique within each reference kind and scope; the first matching definition is used for duplicates. Changes to definitions, labels and selected elements update existing tooltips and lists automatically.

### Navigation and browser history

Opening a reference tooltip does not navigate or add a browser history entry. Tooltips are non-interactive previews. Links from an index generated by `tp-listof` or `tp-global-listof` can navigate to a reference occurrence, including a silent occurrence. Browser Back and Forward restore the previous reading position; embedded multi-page guides keep their parent document’s address unchanged.

### Index references

Use `tp-index` to define a term and `tp-ref href="!term"` to mark each occurrence. The visible label is the reference content, or the entry title when omitted. `silent` marks a location without visible text or a keyboard stop. Use the same `index="name"` on the definition, reference and list to select a named group. Default group: `default`.

`tp-listof selector="tp-index"` produces an alphabetical hierarchy with occurrence links and see/see also cross-references. The optional `title` names the index. See the [Index examples](#/components/index/index.md) for visible references, silent occurrences and multiple indexes.

### Bibliography labels and previews

The optional `label` attribute overrides the displayed reference text. Bibliographic references otherwise use their target `tp-biblio` label when present. Native LaTeX citations use numeric labels while keeping the original citation key in `href`.

### Equation previews

Use `href="=energy"` to reference `<tp-equanum ref="energy" number="2.1">`. The default text is `(2.1)`; `label` may override it. Hover or focus the reference to preview its equation. LaTeX equation references use the same behavior while preserving their original numbers. For align, alignat, flalign, gather and eqnarray, the preview includes only the referenced row and its number.

### Reading long references

Move the pointer from a citation into its tooltip to follow links or scroll a long note or bibliography entry. Previews fit within the viewport and scroll when needed. They remain open while the pointer or keyboard focus is in the citation or preview. Use <kbd>Tab</kbd> to focus the preview or its links, and <kbd>Escape</kbd> to close it.
