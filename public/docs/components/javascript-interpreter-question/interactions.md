### User interactions

#### Mouse interactions

| Action | Result |
| --- | --- |
| Question heading | Opens or closes the exercise. |
| :tp-icon:{name="play-arrow"} Submit | Runs the external tests on the current program. |
| :tp-icon:{name="refresh"} Reset | Restores the initial program and query and clears the report. |
| Source editor | Edit the program before running a query or submitting it. |
| Input / Output | Show or hide the response and feedback panels. |
| Feedback / Solution | Read test results or the supplied solution. |

#### Keyboard interactions

| Key | Result |
| --- | --- |
| <kbd>Enter</kbd> / <kbd>Shift</kbd>+<kbd>Enter</kbd> in the query | Reloads modified source, then executes the query. |
| <kbd>Tab</kbd> | Moves between the editor, query and question controls. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Opens help for the component under the pointer, or the focused component; <kbd>Shift</kbd> may be needed for <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Opens contextual component help. |
