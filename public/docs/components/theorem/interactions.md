### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Statement content | No component-specific mouse interaction. Authored links and nested components retain their normal behavior. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| Statement content | No component-specific keyboard interaction. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User Help for the component under the pointer or currently focused. Include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component in the current hierarchy and open its help. |
