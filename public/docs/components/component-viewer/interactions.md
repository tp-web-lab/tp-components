### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Doc / Demo / API | Show the user documentation, interactive demo or complete API, while preserving the preview configuration. |
| Documentation tabs | Display the selected interactions or API table. |
| Content (HTML) | Edit the component’s inner content and update the preview and all five markup sources. Clear removes the content; Reset defaults restores the original content. |
| Markup source (`</>`) | Show or hide readonly HTML, tp-asciidoc, tp-latex, tp-markdown and tp-restructuredtext tabs below the preview. Attribute edits, clearing, reset and changes reflected by the preview update this source. |
| Boolean checkboxes | Add or remove attributes on the preview. |
| Choice lists | Select a documented configuration value. |
| Text fields | Edit a value and leave the field to apply it. Clear removes the attribute and leaves the field empty. |
| Preview | Interact with the component; reflected attribute changes update the controls. |
| Reset defaults | Restore the documented attribute defaults and restart the preview. |
| Reload preview | Restart the preview with current settings, including initialization-only attributes. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move through configuration controls and the preview. Leaving an edited field applies its value. |
| Arrow keys / <kbd>Home</kbd> / <kbd>End</kbd> on API tabs | Select the adjacent, first or last API tab. |
| <kbd>Space</kbd> | Toggle the focused checkbox. |
| Arrow keys | Change the selection in a focused radio list. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activate the focused action button. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User help for the component under the pointer, falling back to the focused component; <kbd>Shift</kbd> may be needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component from the hierarchy under the pointer, or around the focused component, then open its help. <kbd>Alt</kbd> is <kbd>Option</kbd> on macOS; include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
