### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Files → Import → format | Choose a source file; its extension determines the language and selects its tab. |
| Files → Export as → format | Choose a filename and save the document in that format. |
| Language tabs | Compare the five source formats. |
| :tp-icon:{name="fullscreen" size="2em"} :tp-icon:{name="fullscreen-exit" size="2em"} :tp-icon:{name="theme-light-dark" size="2em"} :tp-icon:{name="palette-swatch" size="2em"} Color / Theme / Fullscreen | Change the converter appearance or open it fullscreen. |
| :tp-icon:{name="file" size="2em"} Files | Import a document or save it in another markup format. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Tab</kbd> | Move between controls. |
| <kbd>Left</kbd> / <kbd>Right</kbd> | Move between focused tabs. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activate the focused control. |
| <kbd>Escape</kbd> | Close the Files menu. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open help for the component under the pointer, falling back to the focused component. <kbd>Shift</kbd> may be needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component in the hierarchy and open its help. |
