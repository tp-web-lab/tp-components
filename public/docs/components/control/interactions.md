### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Controllers | Opens or closes the selection dropdown. |
| All controllers | Shows all controllers when some or none are visible; hides all when all are visible. A partial check indicates a mixed selection. |
| Clock, Language, Color, Theme, Screen, Fullscreen | Shows or hides the corresponding controller in the toolbar to the left. Checked choices are visible. |
| Outside the dropdown | Closes the selection dropdown. |
| Visible controllers | Opens the selected controller's own interface. Hiding a controller retains its setting. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> on Controllers | Opens or closes the dropdown. Opening focuses All controllers. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Moves between visible controls and checkboxes. |
| <kbd>Space</kbd> on a checkbox | Shows or hides the corresponding controller; All controllers changes the whole selection. |
| <kbd>Escape</kbd> | Closes the dropdown and returns focus to Controllers. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User Help for the component under the pointer, or the focused component if none is hovered. Include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component from the hierarchy under the pointer, or around the focused component, then open its help. <kbd>Alt</kbd> is <kbd>Option</kbd> on macOS; include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
