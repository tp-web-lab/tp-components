Global lists

Read the two chapters, then open Appendices in the navigation menu.

  • List of figures shows the four figures and their captions from both chapters, with links to the originals.
  • List of tables displays tables and captions grouped by section, with links to the originals.
  • List of equations shows four equations and links to their source pages, preserving numbers (1) and (2) in each chapter.
  • List of codes displays labelled code blocks grouped by chapter, with links to their original locations.
  • List of theorems shows only theorems with their local numbering and links to the original chapters.
  • List of definitions collects only definitions, using an attribute selector.
  • List of notes links to each chapter's local note definition.
  • Glossary collects the terms defined in the two chapters.
  • Bibliography merges the shared handbook and links to every citation, while keeping different regional guides separate.
  • Index locates the subjects introduced in each chapter.

The lists provide page and anchor links without changing local reference scopes or numbering.
