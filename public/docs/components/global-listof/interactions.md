### User interactions

#### Mouse interactions

| Action | Result |
| --- | --- |
| Click a section heading | Expands or collapses its figures, tables, equations, code blocks, theorems or notes. |
| Click an entry link | Opens its page and scrolls to the target anchor. |

#### Keyboard interactions

| Key | Result |
| --- | --- |
| <kbd>Tab</kbd> | Moves between section headings and visible entry links. |
| <kbd>Enter</kbd> | Follows the focused link or toggles the focused section. |
| <kbd>Space</kbd> | Toggles the focused section. |
| <kbd>ArrowUp</kbd> / <kbd>ArrowDown</kbd> | Moves between section headings. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Focuses the first or last section heading. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Opens help for the component under the pointer, or the focused component; <kbd>Shift</kbd> may be needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component in the containing hierarchy and open its User help. |
