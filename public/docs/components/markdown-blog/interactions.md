### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Article title | Open the complete article in the reader. |
| Categories and Tags | Filter the list; both filters apply together and reset pagination. All removes that filter. |
| Previous / Next | Browse the filtered article pages. |
| Back to articles | Return to the same filters and page. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between filters, article titles and page buttons. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activate the focused button or filter option. |
| Arrow keys in a radio group | Select another category or tag using the radio group's standard controls. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open help for the hovered component, falling back to focus; include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component in the hovered or focused hierarchy before opening help. <kbd>Alt</kbd> is <kbd>Option</kbd> on macOS. |
