### User interactions

#### Mouse interactions

| Control or gesture | Result | Shortcut |
| --- | --- | --- |
| Editor text | Place the cursor or select text; edit either side unless readonly. | |
| :tp-icon:{name="previous" size="2em"} Previous difference | Select and reveal the preceding differing block. | <kbd>Alt</kbd>+<kbd>↑</kbd> |
| :tp-icon:{name="next" size="2em"} Next difference | Select and reveal the next differing block. | <kbd>Alt</kbd>+<kbd>↓</kbd> |
| :tp-icon:{name="arrow-right" size="2em"} Copy difference left to right | Replace the selected right-hand block with its left-hand version. Disabled in readonly mode. | |
| :tp-icon:{name="arrow-left" size="2em"} Copy difference right to left | Replace the selected left-hand block with its right-hand version. Disabled in readonly mode. | |
| :tp-icon:{name="refresh" size="2em"} Reset both documents | Restore both loaded originals. Disabled in readonly mode. | |
| Each editor: :tp-icon:{name="file-upload-as" size="2em"} Save as | Choose a filename and save that side's current source. | <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> S |
| Each editor: :tp-icon:{name="keyboard-outline" size="2em"} Keyboard shortcuts | Open the shared tp-code-editor command palette. | <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> <kbd>Shift</kbd> P |
| Each editor: :tp-icon:{name="copy" size="2em"} Copy code | Copy the entire source on that side. | |
| Each editor: :tp-icon:{name="theme-light-dark" size="2em"} Theme | Choose that editor's appearance. | |
| Each editor: :tp-icon:{name="fullscreen" size="2em"} Fullscreen | <kbd>Enter</kbd> or leave fullscreen for that editor. | |
| :tp-icon:{name="palette-swatch" size="2em"} Color | Change the component's brand color. | |
| :tp-icon:{name="theme-light-dark" size="2em"} Theme | Choose light, dark or automatic appearance. | |
| :tp-icon:{name="fullscreen" size="2em"} :tp-icon:{name="fullscreen-exit" size="2em"} Fullscreen | <kbd>Enter</kbd> or leave fullscreen. | |
| Horizontal scrolling | Read long lines independently on either side when wrapping is disabled. | |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>F1</kbd> | Hide or show the focused editor toolbar (shown initially). |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Shift</kbd>+P | Open the focused editor command palette. |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+S | Save the focused document with a chosen filename. |
| <kbd>Alt</kbd>+<kbd>Down</kbd> / <kbd>Alt</kbd>+<kbd>Up</kbd> | Select the next / previous differing block. |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+Z / <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Shift</kbd>+Z | Undo / redo changes in the focused editor, unless readonly. |
| <kbd>Arrow keys</kbd>, <kbd>Home</kbd>, <kbd>End</kbd>, <kbd>Page Up</kbd>, <kbd>Page Down</kbd> | Move through the focused document. |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+A / <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+C | Select all / copy the selected source. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move focus between controls and the editors. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> on a toolbar button | Activate that button. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User Help for the component under the pointer, or the focused component. <kbd>Shift</kbd> may be needed to type ?. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component from the hierarchy and open its User Help. <kbd>Shift</kbd> may be needed to type ?. |
