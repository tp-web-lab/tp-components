### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Fullscreen button | Expand the associated content; activate again to leave fullscreen. In a same-origin Screen preview inside an already fullscreen page, Exit fullscreen leaves the outer fullscreen instead of opening a second fullscreen. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between the available controls. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activate the focused button. |
| Browser fullscreen exit command | Leave fullscreen. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User Help for the component under the pointer, or the focused component if none is hovered. Include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component from the hierarchy under the pointer, or around the focused component, then open its help. <kbd>Alt</kbd> is <kbd>Option</kbd> on macOS; include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
