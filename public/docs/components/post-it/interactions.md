### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Reading | Read the note and use any links or components inside it normally. |
| Dragging the folded pin | Move the folded note without opening it; movements under 4 pixels remain clicks. |
| Header | Drag anywhere on the header except its buttons, using a mouse, pen or touch. Pin and Reset keep their normal actions. In lite mode, drag the pin instead. |
| Note surface | Read, select text or use controls without moving the note accidentally. The note does not block interaction with the rest of the page. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between the pin, reset, header and interactive content in the expanded note. In lite mode, only the pin remains in keyboard navigation. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activate the focused reset or pin button. Reset restores the initial document position; the pin folds or expands the note. |
| <kbd>←</kbd>/<kbd>↑</kbd>/<kbd>→</kbd>/<kbd>↓</kbd> on the header, or on the pin in lite mode | Move the note by 10 pixels. Hold <kbd>Shift</kbd> for 1-pixel steps. |
| <kbd>Escape</kbd> during a drag | Cancel the movement and restore the starting position. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User Help for the component under the pointer, or the focused component if none is hovered. Include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component from the hierarchy under the pointer, or around the focused component, then open its help. <kbd>Alt</kbd> is <kbd>Option</kbd> on macOS; include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
