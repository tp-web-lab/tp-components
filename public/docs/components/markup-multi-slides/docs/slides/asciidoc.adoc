Title:: Markup languages

Prompt:: Which markup language uses directives beginning with two dots?

Form::
+
* Markdown
* reStructuredText
* AsciiDoc
* HTML

Feedback::
+
* Markdown commonly uses punctuation and fenced blocks.
* Correct. reStructuredText directives begin with two dots.
* AsciiDoc block declarations use square brackets.
* HTML uses elements delimited by angle brackets.

Solution:: reStructuredText
