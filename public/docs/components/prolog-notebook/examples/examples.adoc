# Integer constraints

Run all cells in order. The model finds two increasing integers from 1 to 4 whose sum is 5.
====

[script,type="tp/prolog",filename="program.pl"]
====
:- use_module(library(clpfd)).

pair(X, Y) :-
    [X, Y] ins 1..4,
    X #< Y,
    X + Y #= 5.
====

[script,type="tp/markdown"]
====
## Enumerate the solutions

Expect X = 1, Y = 4, then X = 2, Y = 3.
====

[script,type="tp/prolog",filename="query.pl"]
====
pair(X, Y), labeling([], [X, Y]).
====

[script,type="tp/markdown"]
====
## Check the model with PlUnit

All three tests should pass. Change an expected solution to see a failure, then restore it.
Export this notebook as HTML, open the downloaded file and select Run all cells: the same solutions and tests should appear.
Internet access is required to load the components and SWI-Prolog WASM.
====

[script,type="tp/prolog",filename="checks.pl"]
====
:- use_module(library(plunit)).
:- begin_tests(pairs).

test(solutions, all([X, Y] == [[1, 4], [2, 3]])) :-
    pair(X, Y), labeling([], [X, Y]).

test(equal_values, [fail]) :-
    pair(2, 2).

test(outside_domain, [fail]) :-
    pair(0, 5).

:- end_tests(pairs).
====

[script,type="tp/prolog",filename="query.pl"]
====
run_tests(pairs).
====

# Messages and errors

Click inside the first code editor and press <kbd>Shift</kbd>+<kbd>Return</kbd>.
The output displays the message.
A JavaScript console.log message also appears in the same output. The second cell has not run yet.

Then click inside the second code editor and press <kbd>Shift</kbd>+<kbd>Return</kbd>.
The output displays the intentional error. Edit the code and rerun the current cell.

Export this notebook as HTML, open the downloaded file and repeat both shortcuts.
The exported cells use the same simple interpreter presentation and unified output.
Internet access is required to load the components and their execution engines.

# Multiple solutions

The cell uses the simple interpreter mode, with its solution buttons visible.
Its query is already filled in: `answer(X).`

1. Click **Run** to obtain **X = 10**.
2. Click **Next solution** to obtain **X = 20**.
3. Click **All solutions** to obtain the remaining answer, **X = 30**, and finish the query.
4. Click **Clear**, then **All solutions** to display **10, 20 and 30** at once; Run is not required first.

You can also click **Run**, then **Accept** to stop after the first answer.
To verify source reloading, change `answer(10).` to `answer(100).` and click **Run**.
The first answer becomes **X = 100** and **> Program reloaded.** appears.

## Standalone HTML

Use the notebook's **Files → Export HTML** command and open the downloaded file.
Repeat the same steps using the cell's **Run**, **Next solution**, **All solutions** and **Accept** buttons.
**Run all** starts each cell's query and displays its first answer;
use the cell's solution buttons to continue enumerating answers.
If you edited the source before exporting, the exported first answer is **X = 100**.
Internet access is required to load the components and SWI-Prolog WASM.
====

[script,type="tp/prolog",filename="answers.pl",query="answer(X)."]
====
answer(10).
answer(20).
answer(30).
