.Attributes
========
Combine the attributes on one preview. Controls start at the published defaults. Clear leaves a text field empty and removes the corresponding preview attribute; its default remains visible as a placeholder when nonempty. Some defaults intentionally show no content: use the controls to supply it. Reset defaults fills the controls with their defaults again; Reload preview restarts initialization with the current settings.

.Derivative of tan(x)
======
[tp-single-choice-question%random,answer="2",lang="en"]
====
Title::
+
Derivative of the tangent function

Prompt::
+
What is the derivative of latexmath:[f(x) = \tan(x)] at a point where latexmath:[\cos(x) \ne 0]?

Form::
+
* latexmath:[\cos^{2}(x)]

* latexmath:[\displaystyle \frac{1}{\cos^{2}(x)}]

* latexmath:[\displaystyle -\frac{1}{\sin^{2}(x)}]

* latexmath:[\displaystyle \frac{1}{\tan^{2}(x)}]

Feedback::
+
* The square of the cosine belongs in the denominator.

* Correct. Apply the quotient rule to sine divided by cosine.

* This is the derivative of the cotangent, not the tangent.

* The reciprocal square of the tangent is not its derivative.

Solution::
+
latexmath:[\displaystyle f'(x) = \frac{1}{\cos^{2}(x)} = 1 + \tan^{2}(x)], wherever latexmath:[\cos(x) \ne 0].

.Regular heptagon
======
[tp-single-choice-question%random,answer="3",lang="en"]
====
Title::
+
Recognize a regular heptagon

Prompt::
+
Which figure is a regular heptagon? Select the polygon with seven equal sides and seven equal interior angles.

Form::
+
* {blank}
+
image::/docs/components/single-choice-question/examples/pentagon.svg[Regular polygon with 5 sides,120,120]

* {blank}
+
image::/docs/components/single-choice-question/examples/hexagon.svg[Regular polygon with 6 sides,120,120]

* {blank}
+
image::/docs/components/single-choice-question/examples/heptagon.svg[Regular polygon with 7 sides,120,120]

* {blank}
+
image::/docs/components/single-choice-question/examples/octagon.svg[Regular polygon with 8 sides,120,120]

* {blank}
+
image::/docs/components/single-choice-question/examples/nonagon.svg[Regular polygon with 9 sides,120,120]

Feedback::
+
* This pentagon has five sides.

* This hexagon has six sides.

* Correct. This heptagon has seven equal sides and seven equal interior angles.

* This octagon has eight sides.

* This nonagon has nine sides.

Solution::
+
The regular heptagon is the polygon with seven equal sides and seven equal interior angles.
