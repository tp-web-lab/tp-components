+

+

.Square root
======
[tp-fill-blank-question,mode="closed",lang="en"]
====
Answers::
+
. latexmath:[\mathbb{R}_{+}]
. latexmath:[\mathbb{R}_{+}^{*}]
. latexmath:[\frac{1}{2\sqrt{x}}]

Title:: The square root function

Prompt:: Complete the sentence with the mathematical expressions.

Form::
+
The square root function latexmath:[f(x) = \sqrt{x}] is defined on [tp-blank,name="domain",aria-label="Domain"]#domain#, differentiable on [tp-blank,name="differentiability",aria-label="Domain of differentiability"]#differentiability#, and latexmath:[f'(x) =] [tp-blank,name="derivative",aria-label="Derivative"]#derivative#.

Feedback:: Consider whether zero belongs to the domain and whether the derivative exists there.

Solution:: The domain is latexmath:[\mathbb{R}_{+} = \lbrack 0, +\infty)]. The function is differentiable on latexmath:[\mathbb{R}_{+}^{*} = (0, +\infty)], with latexmath:[f'(x) = \frac{1}{2\sqrt{x}}].
