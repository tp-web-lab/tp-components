### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Previous image | Shows the previous image; wraps to the last image when looping is enabled. |
| Next image | Shows the next image; wraps to the first image when looping is enabled. |
| Trackpad scrolling or touch swipe | Scrolls the images along the carousel direction and snaps to an image. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the image viewport and available navigation buttons. |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowRight</kbd> | Selects the previous or next image in the focused horizontal viewport, respecting text direction. |
| <kbd>ArrowUp</kbd> / <kbd>ArrowDown</kbd> | Selects the previous or next image in the focused vertical viewport. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Selects the first or last image in the focused viewport. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the focused navigation button. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User Help for the component under the pointer, or the focused component if none is hovered. Include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose a component from the hierarchy under the pointer, or around the focused component, then open its help. <kbd>Alt</kbd> is <kbd>Option</kbd> on macOS; include <kbd>Shift</kbd> if needed to type <kbd>?</kbd>. |
