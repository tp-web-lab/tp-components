### User interactions

#### Mouse interactions

| Control or gesture | Result |
| --- | --- |
| Word cloud | No component-specific mouse interaction. |

#### Keyboard interactions

| Key or gesture | Result |
| --- | --- |
| Word cloud | No component-specific keyboard interaction. |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | Open User help for the component under the pointer, falling back to the focused component. <kbd>Shift</kbd> may be needed to type <kbd>?</kbd>. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>?</kbd> | Choose which component in the enclosing hierarchy should receive contextual help. |
