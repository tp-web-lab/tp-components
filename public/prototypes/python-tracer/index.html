Local Python execution trace

A local prototype using a Python tracer engine in a disposable Pyodide Worker. No Python Tutor service, advertising or external visualizer. Pyodide itself is loaded from jsDelivr.

Replay the saved Students trace without running Python

Prototype limits: 1,000 recorded events; 60 seconds to initialize; 10 seconds to execute. Stop terminates the Worker. Each recording starts a fresh session. No DOM access or arbitrary imports; not a security sandbox for hostile code.
