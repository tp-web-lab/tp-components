:::glosentry Docutils
A Python documentation processing system that can parse **reStructuredText** and produce HTML.
:::end

:::glosentry Pyodide
A Python distribution compiled to WebAssembly, allowing Python packages to run directly inside the browser.
:::end

:::glosentry directive
A block-level markup instruction. In Markdown playgrounds, extensions can provide directive-like blocks such as `:::bibliography`.
:::end

:::glosentry ABC notation
A plain-text music notation format that can be rendered as sheet music.
:::end
