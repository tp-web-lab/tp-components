# Demostración de idioma

Seleccione un idioma en el menú para cambiar el repositorio de documentación.

Esta es la versión española de la página de demostración.

El repositorio actual es el subdirectorio español.

## Uso básico

El ejemplo es un componente `<tp-markup-multi-pages>` conectado a este repositorio de demostración.

## Modo auto

El selector de idioma incluye `auto` antes de los códigos de idioma explícitos. En modo auto, utiliza el idioma del navegador cuando coincide con uno de los códigos configurados.

## Selector externo

`<tp-lang>` también puede utilizarse fuera de `<tp-markup-multi-pages>` cuando apunta al mismo repositorio.

## Uso en la barra de herramientas

`<tp-markup-multi-pages>` coloca `<tp-lang>` en su barra de herramientas y le pasa la lista `langs` configurada.
